⚙️ Falta ligar no Firebase

Esta é a versão web do Jorne — ela lê o mesmo banco do app do iPhone. Pra funcionar, cole a config do seu projeto no topo do arquivo (constante CFG):

1. console.firebase.google.com → seu projeto.
2. Engrenagem → Configurações do projeto.
3. Em "Seus apps", adicione um app Web (</>) (ou use um existente).
4. Copie o objeto firebaseConfig e cole no CFG.
5. Confirme que tem o campo databaseURL — sem ele o tempo real não conecta.
